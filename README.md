# Secure API Microservice

A secure backend microservice built with Node.js, Express, and MongoDB. Includes JWT authentication, rate limiting, request validation, logging, and modular API routes.

## 🚀 Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Security:** JWT Authentication, Rate Limiting, Input Validation
- **DevOps:** Docker, CI/CD, Linux

## 📌 Features (Planned)
- User registration & login
- JWT-based authentication
- Protected routes
- Rate limiting (prevent abuse)
- Request validation (Joi / Zod)
- Logging & monitoring
- MongoDB models & schemas

## 📅 Roadmap
- Week 1: Project setup + folder structure
- Week 2: Auth system + JWT
- Week 3: Protected routes + validation
- Week 4: MongoDB integration
- Week 5: Deployment (Render / Railway)
